# Analisador de Números
Projeto desenvolvido para consolidar o conhecimento em arrays, funções e análise de dados com JavaScript.

## Funcionalidades
O sistema permite a entrada de números entre 1 e 100, valida se o valor já foi inserido, armazena os dados em uma lista visual e gera estatísticas como o total de elementos, o maior, o menor, a soma e a média dos valores.

## Tecnologias
JavaScript (ES6+)

HTML5

CSS3

## Conceitos Aplicados
A implementação utiliza estruturas de dados (arrays), validação lógica com funções personalizadas, métodos de busca em listas (indexOf), iteração de arrays com laços de repetição e manipulação dinâmica de elementos de formulário (select e option).
